BROWSER HTML BRIDGE

브라우저 HTML 요청 테스트

URL을 입력하면 연결된 Chrome/Edge 브라우저가 페이지를 열고 HTML을 반환합니다.

사이트별 상품·목록 수집 테스트

브라우저 연결 확인 중

헤더·쿠키 지정 (선택)

쿠키 입력을 비우면 브라우저의 기존 쿠키를 사용합니다. 지정하면 해당 요청의 Cookie 헤더 전체를 교체합니다. {}는 쿠키 없이 요청합니다. 입력한 쿠키를 브라우저에 저장하지 않습니다.

지정한 값은 입력 URL의 메인 문서 GET 요청에 적용합니다. 다른 URL로의 리디렉션과 페이지 내부 요청은 브라우저 기본 설정을 사용합니다.

HTTP/HTTPS 사이트를 지원합니다. 쿠키를 별도로 지정하지 않으면 같은 브라우저 프로필의 쿠키와 로그인 상태를 사용합니다.

페이지 로딩과 추가 대기 후의 DOM입니다. 서버가 처음 보낸 HTML 원문과 다를 수 있습니다.

확장을 로드한 후 서버와 브라우저가 연결되어 있어야 합니다. POST /api/fetch로도 요청할 수 있습니다.
